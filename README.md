Sistema de Desconto Progressivo

Este projeto foi desenvolvido em Python.

O programa calcula o desconto que o cliente receberá de acordo com o **valor total da compra** e, em seguida, informa o valor do desconto e o valor final a ser pago.
O programa utiliza as seguintes regras:

 Valor da compra  Desconto 

 Menor que R$ 200,00| 5% 
 De R$ 200,00 até R$ 300,00  10% 
  Maior ou igual a R$ 300,00  15% 

Exemplos

- Compra de **R$ 150,00** → 5% de desconto
- Compra de **R$ 250,00** → 10% de desconto
- Compra de **R$ 300,00** → 15% de desconto
